SMS / WhatsApp wording — Leave Permit & Administrative Leave

Both are Admin-Affairs document forms that currently send no employee notification. This mockup proposes net-new bilingual message wording for each. Same body is used on WhatsApp and SMS (single template, both channels read identically).

Pick one variant per form (or mix & match lines). Sample values are filled in so you can read the real shape — placeholders in {…} below each section.

1 · Leave Permit

تصريح خروج

A short same-day exit permit — hours, not days. Your idea: drop start/end dates and instead say “from the time it was issued, for N hours.” The form captures duration_hours; the issue time comes from the record’s creation timestamp. No fixed end-date exists, so the wording is built around issue time + duration.

Placeholders: {name} · {issue_time} (10:30 AM) · {date} + {weekday} · {hours} (duration_hours) · V3 also {return_time} = issue + hours.

Decisions / data needed for Leave Permit
  • Issue time source: shown time comes from the record’s created_at, stored in UTC — needs a +4 (UAE) conversion, and BookEvent must carry the time (today it only keeps the date).
  • Verb: “issued” (V1) vs “approved” (V2) vs “granted” (V3) — which fits how the permit actually works when the SMS fires?
  • Return time (V3): nice touch, but only meaningful if the permit is genuinely continuous from issue. Drop if permits can start later than issue.
  • Arabic hours plural: 1 → ساعة · 2 → ساعتان · 3–10 → ساعات · 11+ → ساعة (same plural engine already used by the leave SMS).

2 · Administrative Leave

إجازة إدارية

A multi-day leave generated for the manager to sign. Per your note: no “waiting for signature” wording — the message should simply confirm the leave has been created / issued / recorded. The form captures leave_date_range and duration (days). Three framings below, none mentioning the signature.

1Issued · period line factual, structured
English
Dear Ahmed Ali Hassan, Your administrative leave has been issued. Period: 20–22 Jul 2026 (3 days). Al Wathba Rehabilitation Centre10:30 ✓✓
العربية
عزيزي أحمد علي حسن، تم إصدار إجازتك الإدارية. الفترة: 20–22 يوليو 2026 (3 أيام). إدارة مركز الإصلاح والتأهيل بالوثبة10:30 ✓✓

3Created · on record emphasises “on file”

Dear Ahmed Ali Hassan, Your administrative leave for 20–22 Jul 2026 (3 days) has been created and is on record. Al Wathba Rehabilitation Centre10:30 ✓✓
العربية

Placeholders: {name} · {range} (leave_date_range) · {duration} (days). V2 expands weekdays — needs the range parsed into start/end.

Decisions / data needed for Administrative Leave
  • Verb: “issued” (V1) / “registered” (V2) / “created & on record” (V3) — all avoid the signature. Which tone do you want?
  • Date range: the form stores leave_date_range as one pre-formatted string. V1 & V3 use it verbatim (safe); V2’s weekday expansion needs discrete start/end dates (extra parsing).
  • Send timing: the auto-send fires when the form is generated (before the manager’s signature). “Issued / created” is accurate then; “approved” would not be — hence avoided.
  • Optional: drop the count field admin_leaves_this_month from the SMS (it’s an internal control figure, not employee-facing) — confirm.
  • Arabic days plural: 1 → يوم · 2 → يومان · 3–10 → أيام · 11+ → يوماً.
