White-label configuration menu — first start-up guide

A ten-step wizard that runs once on a brand-new install, before any employee data exists. It turns this single-tenant build into a tenant-configured install: identity and branding, reference numbering and barcode symbology, which modules survive, which services appear (and with what emoji), the token dictionary the Word templates are written against, the employee roster, and a bulk import of passport / Emirates-ID scans matched by ID number. Every step carries an Open decisions block — those are the questions that need your answer before this becomes code.
