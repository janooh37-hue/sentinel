White-label configuration menu — first start-up guide

A ten-step wizard that runs once on a brand-new install and can be re-opened afterwards. The install ships empty: no templates, no register categories, no sample data, none of our internal forms. The buyer brings their own Word documents, their own numbering and their own staff list, and the wizard turns those into a working app. Steps carry an Open decisions block; the ones you have already settled are marked Settled.
